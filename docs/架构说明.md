# 架构说明

## 模块划分

```
monkeycode/
├── client.py      # MonkeyCodeClient：205 个公开方法，全部 REST API + WebSocket 封装入口
├── stream.py      # WebSocket 协议层：TaskStream / ControlStream / TerminalStream / JoinTerminalStream
├── session.py     # AgentSession：任务高层会话（断线自动重连 + 事件缓冲）
├── models.py      # 轻量 dataclass（Task / TaskExtraConfig / CaptchaChallenge / APIKeyInfo 等）
├── pow.py         # PoW 验证码求解器（SHA-256 前缀碰撞，FNV-1a + xorshift32 PRNG）
├── links.py       # 预览链接提取（base64 解码 / 转义清洗 / 预览域名过滤）与存活检测
├── errors.py      # 异常层次（MonkeyCodeError -> APIError -> AuthenticationError 等）
├── consts.py      # 枚举常量（TaskType / TaskSubType / CliName）
├── cli.py         # 命令行入口（25+ 命令）
└── session.py     # 会话持久化（session_path Cookie 文件 + 401 自动重登）
```

## 认证与 PoW

1. `POST /api/v1/users/password-login`（密码以明文传输，服务端 bcrypt 校验）
2. 云平台强制验证码：`POST /api/v1/public/captcha/challenge` 获取
   `{challenge: {c, s, d}, token}`，由 `pow.solve()` 本地求解（确定性 PRNG 生成
   salt/target，爆破 nonce 使 `sha256(salt+nonce)` 以 target 开头）
3. `POST /api/v1/public/captcha/redeem` 兑换 `captcha_token`，再携带它登录
4. 登录成功后 Cookie `monkeycode_ai_session` 保存到 `httpx.Client.cookies`
   （可选持久化到 `session_path` 文件）
5. 团队登录走 `POST /api/v1/teams/users/login`，Cookie `monkeycode_ai_team_session`

## 任务模型

- **REST 轮询**：`create_task` -> `get_task` / `list_tasks` -> `wait_task`
- **WebSocket 实时会话**（`/api/v1/users/tasks/stream?id=&mode=`）：
  - 上行 `user-input`：`data` 为 base64(内层 JSON)，内层 `content` 再 base64(文本)
  - 下行事件：`task-started` / `message` / `task-ended` / `task-error` 等
- **控制通道**（`/api/v1/users/tasks/control?id=`）：
  - 上行 `call`：`data` 为 base64(JSON 请求对象)
  - 下行 `call-response`：`data` 为 base64(响应 JSON)
  - 用途：`switch_model` / `restart` / `switch_agent_resources` / `repo_file_list` /
    `repo_read_file` / `repo_file_diff` / `repo_file_changes` 等

## 终端

- REST：`list_terminal_sessions` / `share_terminal` / `close_terminal`
- WebSocket：`/api/v1/users/hosts/vms/{vm_id}/terminals/connect`
  上行 `data` 为 base64(输入字节)，下行 `data` 为 base64(终端输出)
- 共享加入：`/api/v1/users/hosts/vms/terminals/join`（携带分享密码）

## 自托管

- `MonkeyCodeClient(base_url="https://自托管地址")` 即可切换
- WebSocket 自动做 `http(s) -> ws(s)` 转换，协议与云版一致
- 私有化实例的 License / OAuth / OIDC 配置接口已封装（`get_license_status` /
  `build_oauth_login_url` / `build_oidc_login_url` 等）

## 健壮性

- **401 自动重登**：`_request` 捕获 401 后自动重新 `login()` 并重试一次原请求
- **只读重试**：GET/HEAD/OPTIONS 网络抖动自动重试 3 次（指数退避）
- **429 限流**：按 `Retry-After` 等待后重试（仅只读请求）
- **错误友好化**：10606 / 10205 等已知错误码附加中文提示
